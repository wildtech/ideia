# ideia

> **Criou um repositório a partir deste template?** Este arquivo é **seu**: reescreva-o com a visão do seu ambiente (o agente pode fazer isso com você no primeiro projeto) e mantenha só a linha de crédito do fim. O manual do template está no [`README-ideia.md`](README-ideia.md).

Ajudante para organizar ideias e iniciativas em documentos e apresentações, feito para usar com o seu agente de IA preferido (Claude Code, Kiro, Codex ou outro que leia o `AGENTS.md`), mesmo sem experiência técnica. Você escolhe um **roteiro**, o agente **entrevista você**, e de um Markdown saem documentos (docx, html, pdf), apresentações, carrosséis e vídeos, na sua identidade visual.

## Começar

- **Sem GitHub:** [baixe o ZIP](https://github.com/wildtech/ideia/archive/refs/heads/main.zip), descompacte e abra a pasta no seu agente.
- **Com GitHub:** clique em **Use this template** e abra o seu repositório no seu agente.

Depois, diga ao agente: **"Quero começar um projeto."** Como operar o ambiente, criar um projeto, gerar as saídas, atualizar a base e contribuir está no [`README-ideia.md`](README-ideia.md).

## Sobre este ambiente

A definir: para quem é, que projetos tem, o tema usado e com quem falar.
