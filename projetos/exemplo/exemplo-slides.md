# Estrutura de Modelagem de Projetos e Documentos

**Roteiro:** tldr
**Público da apresentação:** A definir
**Status do documento:** Rascunho, em construção.

---

### A ideia

- Transformar textos e imagens de apoio em **documentos e apresentações** de projetos
- Guiada por **roteiros**: conjuntos de perguntas
- Com identidade visual própria: o **tema**

> Notas: resumo da seção "Sobre / Contexto" do documento completo. O fluxo lembra um analista de negócios que entrevista.

### Como funciona

1. Escolher o **roteiro**
2. Responder às perguntas, com um assistente de IA que entrevista
3. Gerar as **saídas**: documento completo, resumo e apresentação

> Notas: fonte: seções "Os conceitos e como se encaixam" e "Onboarding".

### Para quem

**Layout:** destaque

Pessoas **não técnicas**

> Notas: o assistente conduz o onboarding, cria os arquivos e roda os comandos. O README traz o mesmo caminho em passos manuais.

### Como se encaixa

| Conceito | Responde a |
| :--- | :--- |
| Roteiro | O que perguntar? |
| Tema | Como parece? |
| Saída | O que é gerado? |
| Artefato | O que mais o projeto guarda? |

### Documento e apresentação

- **Documento:** lido sozinho, completo
- **Apresentação:** falada, uma ideia por slide
- **Resumo (TL;DR):** em todo projeto

> Notas: a apresentação não é convertida do documento; é escrita a partir do resumo.
